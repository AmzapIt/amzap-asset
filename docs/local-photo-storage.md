# ทดสอบเก็บรูป Asset บน local server

โหมดนี้ใช้สำหรับเครื่อง local server ที่มีดิสก์ถาวร **ไม่ใช่ Vercel** โค้ดเริ่มต้นยังใช้ Google Drive เหมือนเดิม จึงไม่เปลี่ยนพฤติกรรมของ Vercel จนกว่าจะตั้งค่าบนเครื่องนั้นเอง

## ตั้งค่าบน local server

1. เลือกโฟลเดอร์รูปที่เป็น absolute path และอยู่นอกโฟลเดอร์โปรเจ็กต์ เช่น `D:\AMZAP-Photos` บน Windows หรือ `/srv/amzap/photos` บน Linux ห้ามใช้ `public`, `.next` หรือโฟลเดอร์ที่ถูกแทนที่เมื่อ deploy
2. ให้บัญชีที่รันเว็บมีสิทธิ์อ่าน/เขียนโฟลเดอร์นั้น ไม่ต้องเปิดโฟลเดอร์เป็น network share หรือ web static directory
3. เพิ่มใน `.env.local` **เฉพาะ local server**:

   ```env
   ASSET_PHOTO_STORAGE=local
   ASSET_PHOTO_DIR=D:\AMZAP-Photos
   ```

   ถ้าใช้ Linux เปลี่ยน path ให้ตรงเครื่อง อย่าใส่ `NEXT_PUBLIC_` นำหน้า และอย่า commit `.env.local`
4. Restart แอป (`npm run build` แล้ว `npm start` หากรันแบบ production) จากนั้นอัปโหลดรูปทดสอบจากหน้า Asset หรือ `/scan` แล้วเปิดลิงก์รูปหลัก ระบบจะสร้างโฟลเดอร์ย่อยตาม Asset ID อัตโนมัติ

รูปใหม่ยังจำกัด JPG/PNG/WebP ไม่เกิน 4 MB และผ่านขั้นตอนย่อรูปจาก Browser ตามเดิม ชื่อไฟล์จริงเป็น UUID เพื่อไม่ชนกัน ส่วน DB เก็บชื่อที่อ่านง่ายและ URL `/api/assets/<id>/photos/<ชื่อไฟล์จริง>` การอ่าน URL นี้ต้องล็อกอินและตรวจว่ามีรายการรูปใน DB ก่อน รูปเก่าบน Google Drive ยังคงเปิดผ่านลิงก์เดิม ไม่มีการย้ายหรือลบรูปเก่า และไม่ต้องเพิ่ม migration

ถ้า `ASSET_PHOTO_STORAGE=local` แต่ไม่ตั้ง `ASSET_PHOTO_DIR` เป็น absolute path นอกโปรเจ็กต์ ระบบจะปฏิเสธการอัปโหลดพร้อมแจ้งตั้งค่าใหม่ ไม่ย้อนกลับไป Drive เงียบ ๆ

## ข้อควรระวังระหว่างทดสอบคู่กับ Vercel

หาก local server และ Vercel ชี้ไป **ฐานข้อมูลเดียวกัน** การอัปโหลดบน local จะเพิ่มแถวรูปใน DB ที่ Vercel มองเห็น แต่ Vercel อ่านไฟล์บนดิสก์ local ไม่ได้ ลิงก์รูปใหม่นั้นจะเปิดจากเว็บ Vercel ไม่สำเร็จ ควรใช้ฐานทดสอบแยก หรือใช้ Asset ทดสอบโดยยอมรับผลนี้ก่อน ห้ามเข้าใจว่าโหมด local ทำให้รูปพร้อมใช้จากทั้งสองเว็บ

ถ้าจะใช้งานจริงด้วย storage แบบ local ต้องสำรอง **ทั้งฐานข้อมูลและโฟลเดอร์รูป** เป็นชุดเดียวกัน หากย้าย server อีกครั้งต้องย้ายโฟลเดอร์รูปไปด้วย และตั้ง path ใหม่ใน `.env.local` เว็บ Vercel ควรคง `ASSET_PHOTO_STORAGE=google_drive` ไว้จนกว่าจะวางระบบเก็บรูปที่ทั้งสองเว็บเข้าถึงได้
