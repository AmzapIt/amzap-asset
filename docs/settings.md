# Settings

เปิด `/settings` หลังเข้าสู่ระบบ แถบด้านบนรวมภาพรวมระบบ, รูป Asset, สติ๊กเกอร์, รูปแบบเอกสาร, Master Data, System Accounts และ Change Password

## รูป Asset

- บน local server ผู้ดูแลระบบเลือก Google Drive หรือ Local server, แก้ Google Drive Folder ID หรือ absolute path เก็บรูป แล้วกดบันทึกได้ ค่าอยู่ใน `.server-settings.json` เฉพาะโฟลเดอร์ติดตั้งนั้น ไม่อยู่ในฐานข้อมูลและไม่ถูก commit
- การเปลี่ยนมีผลกับรูปใหม่เท่านั้น รูปเดิมไม่ถูกย้ายหรือลบ OAuth Client ID, Client Secret และ Refresh Token ยังต้องตั้งใน environment ของเซิร์ฟเวอร์
- บน Vercel หน้า Settings อ่านค่าได้อย่างเดียว ต้องแก้ Environment Variables ผ่าน Vercel ค่า local server ไม่เปลี่ยน Vercel แม้ใช้ฐานข้อมูลเดียวกัน
- ก่อนเลือก Local server ให้สร้างโฟลเดอร์นอกโปรเจกต์และให้บัญชีที่รันเว็บอ่าน/เขียนได้ กรอก path แล้วใช้ปุ่มตรวจสิทธิ์ path ที่กรอกก่อนบันทึก จากนั้นกดบันทึกการจัดเก็บรูป ค่า path จะต้องสำรองพร้อมโฟลเดอร์รูปและฐานข้อมูล
- บน Windows ใช้ path แบบ `D:\AMZAP-Photos` หรือแชร์แบบ `\\server\share\Asset` ได้ (รูปแบบ `//server/share/Asset` ก็ใช้ได้) โดยบัญชีที่รันเว็บต้องมีสิทธิ์ทั้งที่แชร์และโฟลเดอร์ปลายทาง การตรวจ path ไม่ได้บันทึกหรือเปลี่ยนที่เก็บรูป
- หาก local server กับ Vercel ใช้ฐานข้อมูลเดียวกัน Vercel จะเห็นรายการรูปที่เพิ่มบน local แต่เปิดไฟล์ในดิสก์ local ไม่ได้

## สติ๊กเกอร์

กระดาษคงขนาด 40 × 30 มม. ค่า QR, ขนาดตัวอักษร และระยะชดเชยบันทึกในเบราว์เซอร์ของเครื่องที่สั่งพิมพ์ มีผลกับตัวอย่างและงานพิมพ์ถัดไป ไม่แก้ QR payload หรือประวัติพิมพ์ ทดสอบหนึ่งดวงหลังเปลี่ยนค่า

## ภาพรวมและเอกสาร

จำนวน In Use และสถานะฐานข้อมูลอ่านสด วันที่สำรองข้อมูลจะแสดงว่าไม่ทราบจนกว่าจะเชื่อมระบบสำรองจริง รูปแบบเอกสารแสดงค่าปัจจุบันเท่านั้น; ชื่อบริษัทและโลโก้ยังแก้จากหน้าเว็บไม่ได้เพื่อไม่ให้เอกสารบน local/Vercel ต่างกันโดยไม่ตั้งใจ
